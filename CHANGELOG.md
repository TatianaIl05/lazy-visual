# Changelog

## 0.1.0

First public release.

### Added

- `scatterplot`, `distribution`, `box`, `violin`, `raincloud`, `heatmap`, `upset`, `roc`
- `lv.load` (csv/tsv/parquet/excel/json + URL)
- 4 themes: default, nature, apa, dark
- Built-in stats: Mann-Whitney U, Welch t-test, Kruskal-Wallis, Holm correction, Cohen's d, KDE, DeLong & bootstrap AUC CI
- Error codes LV-E101..E310, LV-W501..W504
