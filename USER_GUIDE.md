# Инструкция пользователя `lazy-visual`



## 0. Введение



\- \textbf{Название проекта:} `lazy-visual`

\- \*\*Ссылка на работающий MVP:\*\* https://github.com/TatianaIl05/lazy-visual

\- \*\*Для кого этот продукт:\*\* для аналитиков данных, исследователей, студентов и научных сотрудников, которые работают в Python (pandas/NumPy) и хотят строить статистические графики без переключения между несколькими библиотеками.

\- \*\*Что он делает:\*\* одной строкой кода строит статистический график и сразу возвращает встроенную статистику (p-value, Cohen's d, AUC с 95% доверительным интервалом).

\- \*\*Сколько времени займёт знакомство:\*\* 5 минут до первого графика.

## 2. Основная функция №1: `raincloud`



\*\*Название функции:\*\* `lv.raincloud(data, x=..., y=..., ...)` - рисует raincloud-plot (комбинация half-violin, box и jittered-точек) и автоматически считает статистику между группами.



\*\*Зачем она нужна пользователю:\*\*



Закрывает боль «нужно показать распределение по группам, но seaborn не даёт p-value, а statsmodels слишком сложен». Один вызов - один график + готовые p-value и Cohen's d. Не нужно вручную вызывать Mann-Whitney U, Cohen's d, строить три слоя графика и подписывать результаты.



\*\*Пошаговая инструкция:\*\*



1\. Пользователь импортирует библиотеку и готовит данные в pandas:



&#x20;  ```python

&#x20;  import numpy as np

&#x20;  import pandas as pd

&#x20;  import lazy\_visual as lv



&#x20;  rng = np.random.default\_rng(0)

&#x20;  df = pd.DataFrame({

&#x20;      "group": rng.choice(\["control", "drug\_a", "drug\_b"], 300),

&#x20;      "score": rng.normal(0, 1, 300) + rng.choice(\[0, 1, 2], 300),

&#x20;  })

&#x20;  ```



2\. Затем вызывает одну функцию:



&#x20;  ```python

&#x20;  result = lv.raincloud(

&#x20;      df, x="group", y="score",

&#x20;      pairs=\[("control", "drug\_a"), ("control", "drug\_b")],

&#x20;      title="Score by group",

&#x20;      save="raincloud.svg",

&#x20;  )

&#x20;  ```



3\. Система обрабатывает запрос за \*\*\~1-2 секунды\*\* (на 300 строк). При больших данных срабатывает подвыборка до 5000 точек на группу с предупреждением `\[LV-W502]`.



4\. Пользователь получает:

&#x20;  - файл `raincloud.svg` (или PNG/PDF — см. `fmt=`);

&#x20;  - объект `LvResult`, в котором:

&#x20;    - `result.fig` - matplotlib `Figure`,

&#x20;    - `result.stats` - список `StatResult` (Kruskal-Wallis + Mann-Whitney U для указанных пар + Cohen's d),

&#x20;    - `result.files` - список путей сохранённых файлов.



\*\*Пример входных данных:\*\* DataFrame с колонками `group` (категориальная) и `score` (числовая), 300 строк, 3 группы.



\*\*Пример результата:\*\*



```

<LvResult raincloud, Kruskal-Wallis p < 0.001, saved: raincloud.svg>

```



На графике: три группы `control`, `drug\_a`, `drug\_b`; над парами скобки с `p = 0.002, d = -0.65` и `p = 0.041, d = -0.31`.

## 3. Основная функция №2: `roc`



\*\*Название функции:\*\* `lv.roc(data, y\_true=..., y\_score=...)` - строит ROC-кривые для одной или нескольких моделей и считает AUC с 95% доверительным интервалом методом DeLong.



\*\*Зачем она нужна:\*\*



Закрывает боль «нужно посчитать AUC с CI, но sklearn не даёт CI, а pROC есть только в R». Пользователь передаёт бинарные метки и один или несколько скоров - получает готовый график с AUC + CI в легенде. Метод DeLong реализован на NumPy без sklearn.



\*\*Пошаговая инструкция:\*\*



1\. Пользователь готовит DataFrame с бинарной меткой `y\_true` и одним или несколькими колонками со скором:



&#x20;  ```python

&#x20;  df = pd.DataFrame({

&#x20;      "y\_true": \[0, 0, 1, 1, 1, 0, 1, 0, 1, 1, 0, 0],

&#x20;      "model\_a": \[0.1, 0.2, 0.75, 0.85, 0.9, 0.15, 0.8, 0.3, 0.7, 0.95, 0.25, 0.2],

&#x20;      "model\_b": \[0.2, 0.3, 0.6, 0.7, 0.8, 0.25, 0.75, 0.35, 0.65, 0.85, 0.4, 0.3],

&#x20;  })

&#x20;  ```



2\. Вызывает `lv.roc`:



&#x20;  ```python

&#x20;  result = lv.roc(

&#x20;      df, y\_true="y\_true", y\_score=\["model\_a", "model\_b"],

&#x20;      ci=True, ci\_method="delong",

&#x20;      title="ROC curves",

&#x20;      save="roc.svg",

&#x20;  )

&#x20;  ```



3\. Система обрабатывает запрос за \*\*\~0.5-2 секунды\*\* для стандартных данных. Для 100 000 строк и 3 моделей - \*\*\~120 мс\*\* на статистику, ещё немного на рендер.



4\. Пользователь получает:

&#x20;  - файл `roc.svg` с кривыми и диагональю;

&#x20;  - `result.stats` - список `StatResult` с `estimate` (AUC), `ci\_low`, `ci\_high`.



\*\*Пример входных и выходных данных:\*\*



Вход - `y\_true` (2 класса) + `y\_score` (одна или несколько моделей). Выход:



```

<LvResult roc, ROC AUC, saved: roc.svg>

```



Легенда графика:



```

model\_a: AUC 0.871 \[0.842, 0.899]

model\_b: AUC 0.813 \[0.781, 0.845]

```

## 4. Основная функция №3: `upset`



\*\*Название функции:\*\* `lv.upset(data, ...)` - строит UpSet-plot для пересечений множеств и возвращает таблицу эксклюзивных пересечений.



\*\*Зачем она нужна:\*\*



Закрывает боль «диаграмма Венна показывает только 2–3 множества и не даёт чисел». UpSet показывает до 20 множеств и точные размеры каждого эксклюзивного пересечения. Пользователь сразу видит не только «что пересекается», но и «сколько элементов в каждом пересечении».



\*\*Пошаговая инструкция:\*\*



1\. Пользователь готовит данные одним из трёх способов:

&#x20;  - \*\*dict of sets:\*\* `{"A": {1,2,3}, "B": {2,3,4}, "C": {3,4,5}}`;

&#x20;  - \*\*широкий DataFrame\*\* с bool-колонками;

&#x20;  - \*\*long DataFrame\*\* с колонками `item` и `set\_col`.



&#x20;  Пример:



&#x20;  ```python

&#x20;  data = {

&#x20;      "set\_A": {1, 2, 3, 4, 5},

&#x20;      "set\_B": {3, 4, 5, 6},

&#x20;      "set\_C": {4, 5, 6, 7},

&#x20;  }

&#x20;  ```



2\. Вызывает функцию:



&#x20;  ```python

&#x20;  result = lv.upset(

&#x20;      data,

&#x20;      top\_n=10, min\_size=1, sort\_by="size",

&#x20;      title="Intersections across A / B / C",

&#x20;      save="upset.svg",

&#x20;  )

&#x20;  ```



3\. Система обрабатывает запрос за \*\*<1 секунды\*\* для стандартных размеров. Для >30 пересечений - обрезает по `top\_n` (по умолчанию 30).



4\. Пользователь получает:

&#x20;  - файл `upset.svg` с тремя панелями (bars сверху, matrix по центру, sets слева);

&#x20;  - `result.tables\["intersections"]` - DataFrame с колонками `pattern` (кортеж сетов), `size`, `degree`.



\*\*Пример результата:\*\*



```

<LvResult upset, saved: upset.svg>

```



`result.tables\["intersections"]`:



```

&#x20;       pattern  size  degree

0  (A, B, C)     2       3

1     (A, B)     1       2

2        (B, C)  1       2

3           (A,) 2       1

4           (C,) 1       1

```

## 5. Что делать, если что-то пошло не так



\*\*Ошибка №1:\*\* `LvDataError: \[LV-E101] Column 'dose' not found. Available: group, score, age.`



→ \*\*Что делать:\*\* проверьте точное имя колонки (регистр важен). Библиотека подскажет ближайший вариант через `difflib`. Посмотрите `df.columns`.



\*\*Ошибка №2:\*\* `LvArgumentError: \[LV-E201] Argument 'dpi' = 1 is out of range. Allowed: 72-1200.`



→ \*\*Что делать:\*\* значение `dpi` должно быть в диапазоне 72–1200. По умолчанию 150, при `save=` - 300. Уберите параметр или поставьте корректный.



\*\*Ошибка №3:\*\* `LvDataWarning: \[LV-W501] Dropped 12 rows with NaN in required columns.`



→ \*\*Что делать:\*\* это предупреждение, не ошибка. Библиотека автоматически удалила строки с NaN в нужных колонках и продолжила построение. Если хотите сохранить контроль - заранее сделайте `df.dropna(subset=\["group", "score"])` или заполните значения.



\*\*Ошибка №4:\*\* `LvExportError: \[LV-E301] Unsupported export format 'bmp'. Use png/svg/pdf.`



→ \*\*Что делать:\*\* `save=` принимает только `.png`, `.svg`, `.pdf`. Укажите одно из этих расширений.

## 6. Частые вопросы (FAQ)



\*\*Вопрос 1: Обязательно ли использовать pandas? Можно ли передать NumPy-массив или список?\*\*



→ Нет, pandas не обязателен. Библиотека принимает pandas DataFrame, polars DataFrame, NumPy-массив, dict или список кортежей. NumPy-массив без имён колонок автоматически получит имена `x0, x1, ...`. Но для графиков с `x=...`/`y=...` удобнее DataFrame - так явно задаются имена колонок.



\*\*Вопрос 2: Как поменять цвета, шрифт, размер графика?\*\*



→ Используйте встроенные темы: `lv.theme("nature")` (Arial 7pt, палитра Okabe-Ito), `lv.theme("apa")`, `lv.theme("dark")`, `lv.theme("default")`. Или передавайте аргументы в вызов: `lv.raincloud(..., palette="okabe", alpha=0.7, figsize=(6, 4))`. Все аргументы стиля - keyword-only, приоритет: явные аргументы > тема вызова > активная тема > дефолты.



\*\*Вопрос 3: Поддерживается ли Windows?\*\*



→ Да. CI-матрица проверяет Linux, macOS и Windows × Python 3.10-3.13. Единственное отличие - `matplotlib` использует backend `Agg`, поэтому интерактивные окна не открываются: графики сохраняются в файл или отображаются в Jupyter через `result.show()`.



\*\*Вопрос 4: Можно ли строить несколько графиков в одной фигуре?\*\*



→ Да, через аргумент `ax=`. Создайте subplots сами и передайте `ax` в функцию:



&#x20;  ```python

&#x20;  fig, axes = plt.subplots(2, 2)

&#x20;  lv.box(df, y="score", x="group", ax=axes\[0, 0])

&#x20;  lv.violin(df, y="score", x="group", ax=axes\[0, 1])

&#x20;  ```



&#x20;  Исключение - `upset`: у него три панели, поэтому `ax=` с ним несовместим (вернёт `LV-E204`).



\*\*Вопрос 5: Где найти список всех кодов ошибок?\*\*



→ На странице документации \*\*Error codes\*\*: https://tatianail05.github.io/lazy-visual/errors/. Там таблица всех `LV-E101…E310`, `LV-W501…W504` с описанием ситуации. Формат сообщения всегда один: `\[LV-E101] message. Hint: ...`.
